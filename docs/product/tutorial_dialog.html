Tutorial Dialog

Implemented 4-slide modal

One-time modal walkthrough teaching new users the core gameplay loop: dice → combat → tier → gear. Triggered automatically when tutorialCompletedAt is null. Skippable but non-dismissible (ESC/overlay blocked).

Trigger & Persistence

Dismiss Semantics
Skip = complete. Both Skip and Got it call onComplete. ESC and overlay click are blocked (onEscapeKeyDown + onPointerDownOutside → preventDefault). No path closes the modal without persisting tutorialCompletedAt.

Database

prismaprisma/schema.prisma
model Character {
  // ... existing fields
  tutorialCompletedAt DateTime? @db.Timestamp(6)
}
sqlBackfill — skip modal for users who already understand the loop
UPDATE characters c
SET tutorial_completed_at = NOW()
WHERE EXISTS (
  SELECT 1 FROM character_classes cc WHERE cc.character_id = c.id AND cc.tier > 1
)
   OR jsonb_array_length(COALESCE(c.loadout, '[]'::jsonb)) > 0
   OR EXISTS (
  SELECT 1 FROM character_quests cq WHERE cq.character_id = c.id AND cq.completed_at IS NOT NULL
);

Backend

typescriptcharacter.service.ts
async completeTutorial(userId: string) {
  return this.characterRepository.setTutorialCompletedAt(userId, new Date())
}
async resetTutorial(userId: string) {
  return this.characterRepository.setTutorialCompletedAt(userId, null)
}

Zustand Store

typescriptsrc/stores/tutorial.store.ts
type TutorialState = {
  manuallyClosed: boolean
  setClosed: () => void
  reopen: () => void
}

export const useTutorialStore = create<TutorialState>((set) => ({
  manuallyClosed: false,
  setClosed: () => set({ manuallyClosed: true }),
  reopen: () => set({ manuallyClosed: false })
}))
