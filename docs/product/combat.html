Combat System

Pokémon-style turn-based Phase 2B

Replaced the dice-roll system in Phase 2A. A Quest is one character's run through an ordered sequence of Encounters. Real-life productivity actions fuel in-game mana power.

Resources

❤ HP (Health)
Lives on CharacterClass.health. Multiplied ×5 to calibrate 3–4 hit fights at parity tier. Persists across encounters; restored on quest start / revive.
✦ Mana
Single combat resource. No per-turn regen — spent mana refills only from Reserve at the next Encounter start. Budget = maxMana (range 5–14 per class/tier).
◈ Reserve
Uncapped overflow bank on Character.manaReserve. Earned by completing real-life tasks, habits, objectives, and journal entries.

Turn Structure

Damage Formula

Pokémon Generation-1 formula, calibrated for 3–4 hit fights at parity tier.

level = unit.tier * 10 + 10 // tier 1 → L20, tier 2 → L30, tier 3 → L40
variance = 0.85 + Math.random() * 0.30 // ±15%
isCrit = Math.random() < 1/16 // 6.25% base, 2× damage
damage = floor((((2*L/5 + 2) * power * atk/def) / 50) + 2) * variance * (isCrit ? 2 : 1)

Attack stat selection

  • atk = strengthAtk or magicAtk, picked by move damageType
  • def = matching defender stat, floored at 1

Implementation

  • Formula: src/server/utils/combat/combat-formula.ts
  • Orchestration: move-resolution.ts
  • Self-buffs / Protect / cleanse carry no power

Enemy AI

executeEnemyMove in move-resolution.ts. Selection algorithm:

  1. Build pool from enemy.moves[]. Fall back to ['basic_strike'] if empty.
  2. Filter out moves where manaCost > currentMana.
  3. If currentHealth / maxHealth ≤ 0.3, restrict to damage moves (isDamageMove). If that empties pool, revert to affordable set.
  4. Sort by manaCost descending. Pick uniformly at random among highest-cost entries.
  5. Final fallback: basic_strike.
Design Note
Picking "most expensive affordable" (not literal-cheapest) ensures curated movesets are used. Always picking cheapest would default to basic_strike and defeat the point of custom moves.

Items & Class Stats

Items contribute flat bonuses. A full T3 weapon roughly doubles class ATK (~Pokémon Choice Band magnitude).

Weapons
strengthAtkBonus or magicAtkBonus + speed adds to turn order.
Armor
strengthDefBonus, magicDefBonus.
Health Potion
Heals 15 HP (×5 rescaled). Usable once per encounter.
Mana Potion Removed
mana_potion is removed — no mid-fight mana refill. Existing rows scrubbed by ManaService.scrubManaPotions with 25g refund per row (idempotent, currently uncalled — see TODO).

Known Limits (Beta)
  • No Tier 4 abilities for any class. Tier 4 enemies have placeholder movesets.
  • Inquisitor + Demon Hunter have no defined abilities at any tier — ship class-stat-only.
  • Balance is untuned beyond fight-count tests. Empirical playtest data still to come.
  • No combat e2e tests. Move-resolution covered by unit + integration suites; orchestration verified by manual playthrough.
  • No sound, no animation polish. Tracked as Combat Phase 3 in TODO.md Backlog.
