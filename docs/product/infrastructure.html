Deployment Options

⭐ Option 1: Hetzner VPS

Recommended — lowest cost

CX22 (4GB RAM) — ~€5/month total

  • PostgreSQL in Docker
  • Next.js app in Docker
  • Caddy reverse proxy
Option 2: Railway

Managed, easier ops.

~$12–20/month

  • app service (Next.js, Dockerfile)
  • PostgreSQL plugin (~$7/mo)
  • Upstash free tier
Option 3: Vercel + DB

Zero-config deploy.

~$0–15/month

  • Vercel (Next.js)
  • Neon serverless PostgreSQL
  • Upstash Redis
  • Caveat: cold starts affect Pino logging

Hetzner Docker Compose (Recommended)

yamldocker-compose.production.yml
services:
  postgres:
    image: postgres:16-alpine
    volumes:
      - postgres_data:/var/lib/postgresql/data
    deploy:
      resources:
        limits:
          memory: 1.5G

  app:
    build: .               # Next.js Dockerfile
    environment:
      - DATABASE_URL=postgresql://postgres:5432/arq
      - UPSTASH_REDIS_REST_URL=${UPSTASH_REDIS_REST_URL}
    deploy:
      resources:
        limits:
          memory: 1G

  caddy:
    image: caddy:2-alpine
    ports:
      - '80:80'
      - '443:443'
    volumes:
      - ./Caddyfile:/etc/caddy/Caddyfile
      - caddy_data:/data

Scaling Path

Phase 1 — MVP
0–1,000 users · ~€5/month
Single Hetzner CX22 VPS (4GB RAM). PostgreSQL + Next.js on same machine. Upstash free tier.
Phase 2 — Growth
1,000–10,000 users · ~€15–30/month
Upgrade to CX32 (8GB) or CX42 (16GB). Move PostgreSQL to managed (Neon or Railway). Upstash paid tier.
Phase 3 — Scale
10,000+ users · ~€50–100/month
Separate database server. Load balancer (Hetzner LB: €5.39/mo). Multiple Next.js replicas.
