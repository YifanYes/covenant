Three-room product shape

What each room does

Each room has a distinct product job. The strongest through-line is shared world presence with a low operational footprint.

Phase 1

The Inn

Account-wide rest mode protects streaks and future HP-loss systems while still allowing light engagement.

  • Rest at the Inn CTA
  • Mana and gold still awarded during rest
  • Guild campaigns still receive completions
Phase 2

The Hall

A single global boss turns solo productivity into a visible server-wide encounter.

  • Flat damage by event type
  • HP scales from active users
  • Fixed personal reward plus global unlock
Phase 3

Notice Board

A global, asynchronous posting surface designed to signal community without becoming chat.

  • One post per user per 24h
  • 500-character hard cap
  • No premium posting increases
Shipping path

Independent phases

The spec stays additive. Phase 1 can ship alone; Hall and Notice Board add new surfaces only when the beta needs them.

1

The Inn

Two user columns, Tavern UI, and streak calculations that treat rest windows as non-counting intervals.

2

The Hall

World boss entity, contribution tracking, active-user HP scaling, personal rewards, and global unlocks.

3

Notice Board

One global board, one post per day, 500 characters, report-gated moderation, and no rich media.

Reward model

More helpers never dilute the payout

The revised reward design avoids the bad feeling of a global pool being split into smaller and smaller slices.

1. Eligible event

Habit, task, or enemy defeat records a world boss event with idempotency.

2. Flat damage

Damage is based on event type and capped per user per day.

3. Defeat

A conditional update stamps defeatedAt once when health reaches zero.

4. Claim

Each qualified contributor claims the same fixed personal reward. Global unlock applies server-wide.

Moderation posture

Designed not to become chat

  • No replies, reactions, direct messages, images, or uploads.
  • One global board prevents quiet faction silos during beta.
  • Three reports auto-hide a post pending review.
  • Reading and posting are free; premium never increases posting volume.

Risk register

What to watch

These are the product and operational pressure points that should stay visible during implementation.

Notice Board moderation overrun

Mitigate with 24h cap, keyword block, auto-hide after reports, no uploads, and no premium volume increase.

World boss dead air

Mitigate with active-user HP scaling and template clamps so beta cohorts can still defeat bosses.

Contribution table growth

Index by boss and user; render personal contribution, guild totals, and a capped ticker instead of full public ranking.

Heavy-hitter regression

Keep Hall damage flat by event type, enforce the daily cap, and test that character tier does not dominate outcomes.
